# Security policy

Header Scout is a lightweight review aid, not a vulnerability scanner or a guarantee that a website is secure.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not put exploit details, credentials, cookies, or private target information in a public issue. If private reporting is unavailable, open a minimal issue asking for a private contact route without disclosing sensitive details.

## Scope

Reports about Header Scout itself are in scope. Findings about third-party websites are not authorization to test those websites; contact their owners through their published security process.
